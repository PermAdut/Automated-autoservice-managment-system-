УСТАНОВКА И ЗАПУСК ELECTRON-ПРИЛОЖЕНИЯ (AutoService Desktop)
================================================================

Десктоп-клиент находится в каталоге electron-opus/. Приложение использует
общий UI из frontend/src и подключается к NestJS API на порту 3000.

Схема: electron-opus -> HTTP REST -> NestJS :3000 -> PostgreSQL
       (Redis опционально)

Структура проекта:

  Main / Preload  — electron-opus/src/main, electron-opus/src/preload
                    окно Electron и preload-скрипт

  Renderer (UI)   — frontend/src
                    React-приложение, общее с web-версией

  Сборка          — electron-vite + electron-builder
                    dev-сервер и инсталляторы


ТРЕБОВАНИЯ
----------

На всех платформах (Windows, macOS, Linux) нужны:

  - Node.js 20 LTS или новее
  - npm 10 или новее
  - Git (актуальная версия)
  - Запущенный NestJS API и PostgreSQL (см. README.md в корне репозитория)

Для сборки инсталляторов:

  Windows — собирать только на Windows
            результат: dist/*-setup.exe (NSIS)

  macOS   — собирать только на macOS
            результат: dist/*.dmg, dist/*.zip

  Linux   — на Linux или через Docker (electron-opus/Dockerfile)
            результат: dist/*.AppImage, dist/*.deb

Кросс-компиляция ограничена: build:win надёжно работает на Windows,
build:mac — на macOS. Linux-образ можно собрать через Docker без
установки Node на хост.


1. УСТАНОВКА СИСТЕМНЫХ ЗАВИСИМОСТЕЙ
------------------------------------

Windows
-------

  1. Установить Node.js 20 LTS: https://nodejs.org/ (вместе с npm)
  2. Установить Git for Windows: https://git-scm.com/download/win
  3. Открыть PowerShell или cmd от обычного пользователя
     (не запускать npm от администратора)

  Проверка:

    node -v
    npm -v
    git --version


macOS (POSIX)
-------------

  Через Homebrew:

    brew install node@20 git

  Или через nvm:

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
    nvm install 20
    nvm use 20

  Проверка:

    node -v && npm -v && git --version


Linux (POSIX)
-------------

  Debian / Ubuntu:

    sudo apt update
    sudo apt install -y git curl
    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
    sudo apt install -y nodejs

  Fedora:

    sudo dnf install -y git nodejs npm

  Проверка:

    node -v && npm -v && git --version

macOS / Linux:

3. ЗАПУСК BACKEND (ОБЯЗАТЕЛЬНО)
-------------------------------

Electron-клиент не работает автономно: ему нужен запущенный API.

Минимальный локальный вариант (подробнее в README.md):

  cp server/.env.example server/.env
  (заполнить DB_*, DATABASE_URL, JWT_SECRET)

  cd server
  npm install
  npm run db:push
  npm run db:seed          (опционально — тестовый admin)
  npm run start:dev

API должен отвечать на http://localhost:3000
Swagger: http://localhost:3000/api/docs

Альтернатива — Docker Compose, см. docs/DOCKER_DEPLOY.md

CORS для Electron уже учтён на сервере (server/src/cors-origin.callback.ts):
запросы из desktop с origin null (file://) разрешены.


4. НАСТРОЙКА ELECTRON-ПРИЛОЖЕНИЯ
--------------------------------

Windows:

  cd electron-opus
  copy .env.example .env
  npm install

macOS / Linux:

  cd electron-opus
  cp .env.example .env
  npm install

Отредактировать electron-opus/.env:

  VITE_API_URL=http://localhost:3000
  VITE_APP_NAME=АвтоСервис

Для production-сборки укажите адрес вашего сервера,
например https://api.example.com


5. РЕЖИМ РАЗРАБОТКИ
-------------------

В отдельном терминале (API уже запущен):

Windows:

  cd electron-opus
  npm run dev

macOS / Linux:

  cd electron-opus
  npm run dev

Откроется окно AutoService. Hot reload для renderer включён через electron-vite.

Тестовый вход (после npm run db:seed на сервере):

  Email:    admin@autoservice.ru
  Password: Admin1234!


6. СБОРКА ДИСТРИБУТИВА
----------------------

Сначала production-сборка renderer и main, затем упаковка через
electron-builder. Артефакты появляются в electron-opus/dist/

  npm run build:win     — на Windows, NSIS-инсталлятор
  npm run build:mac     — на macOS, .dmg и .zip
  npm run build:linux   — на Linux, .AppImage и .deb
  npm run build:unpack  — распакованная папка без инсталлятора (для проверки)

Windows:

  cd electron-opus
  npm run build:win

  Установщик: electron-opus\dist\autoservice-desktop-1.0.0-setup.exe

macOS:

  cd electron-opus
  npm run build:mac

  При первом запуске неподписанного .app macOS может заблокировать приложение:
  Системные настройки -> Конфиденциальность и безопасность -> Всё равно открыть

Linux:

  cd electron-opus
  npm run build:linux

  Запуск AppImage:

    chmod +x dist/autoservice-desktop-*.AppImage
    ./dist/autoservice-desktop-*.AppImage

  Установка .deb (Debian/Ubuntu):

    sudo dpkg -i dist/autoservice-desktop_*_amd64.deb

Сборка Linux через Docker (без Node на хосте):

  cd electron-opus
  docker build -t autoservice-desktop-builder .
  docker run --rm -v "$(pwd)/dist:/output" autoservice-desktop-builder

8. УСТРАНЕНИЕ НЕПОЛАДОК
-----------------------

Не удаётся подключиться к серверу / пустой экран после логина:

  - Убедитесь, что API запущен: curl http://localhost:3000/health
    (или откройте Swagger)
  - Проверьте VITE_API_URL в electron-opus/.env
  - После изменения .env перезапустите npm run dev
    или пересоберите production-билд

npm install падает на Windows:

  - Запускайте терминал без прав администратора
  - Удалите node_modules и package-lock.json, затем снова npm install
  - При ошибках native-модулей установите Visual Studio Build Tools:
    https://visualstudio.microsoft.com/visual-cpp-build-tools/
    с workload Desktop development with C++

Electron не стартует после npm run dev:

  - Проверьте, что порт dev-сервера renderer не занят
    (electron-vite выберет свой порт автоматически)
  - Удалите кэш electron-opus/out/ и перезапустите

Сборка macOS: entitlements

  В electron-builder.yml указан build/entitlements.mac.plist.
  Если файла нет в репозитории, создайте каталог electron-opus/build/
  или временно уберите строку entitlementsInherit из конфига перед build:mac

SmartScreen / Gatekeeper блокирует установщик

  Production-сборки не подписаны кодом. Для внутреннего использования —
  подтвердите запуск вручную. Для распространения нужны code signing
  (Windows Authenticode, Apple Developer ID)

Не используйте sudo npm

  На macOS/Linux команды sudo npm install / sudo npm run dev создают
  проблемы с правами на node_modules. Используйте обычного пользователя или nvm
